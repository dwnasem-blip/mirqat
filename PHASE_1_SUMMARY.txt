                      PHASE 2 - NEXT REQUIREMENTS (NOT YET STARTED)

These are items you'll need to prepare for Phase 2:

1. CREATE SUPABASE PROJECT
   • Go to https://supabase.com
   • Create new project
   • Get your SUPABASE_URL and SUPABASE_ANON_KEY
   • Save these in .env.local

2. CHOOSE QURAN DATA SOURCE
   • Quran.com API (requires permission)
   • Local JSON files with trusted data
   • Tanzil.net (structured data)
   • Other Islamic databases
   Note: We will NOT accept random/unverified sources

3. CHOOSE TAFSIR SOURCES
   • Tafsir Ibn Kathir
   • Al-Qortobi
   • Al-Baghawi
   • Must verify copyright/licensing
   Note: We will NOT truncate tafsirs or change meanings

4. HADITH SOURCE SELECTION
   • Sahih Bukhari
   • Sahih Muslim
   • Sunan collections
   • With proper grade assignments
   Note: Must NOT mix authentic with fabricated hadith

5. DECIDE ON ADHKAR SOURCES
   • Authentic dua collections
   • Verified sources only
   • Proper attribution

================================================================================
                          HOW TO GET STARTED
================================================================================

1. Navigate to project:
   $ cd /home/user/mirqat

2. Install dependencies (if not done):
   $ npm install

3. Start development:
   $ npm run web     # Web browser
   $ npm run ios     # iOS (Mac only)
   $ npm run android # Android

4. Type checking:
   $ npx tsc --noEmit

5. View design system:
   • Colors: src/constants/colors.ts
   • Typography: src/constants/typography.ts
   • Spacing: src/constants/spacing.ts
